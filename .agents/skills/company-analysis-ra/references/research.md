# 수집과 기업분석 기준

## 출처 선택

한국 기업은 [DART](https://dart.fss.or.kr/), [OpenDART](https://opendart.fss.or.kr/), [KRX 정보데이터시스템](https://data.krx.co.kr/)과 해당 기업 IR에서 법인·계정·시세·일정을 확인한다. 미국 기업은 [SEC EDGAR](https://www.sec.gov/edgar/search/)와 기업 IR을 확인한다. 데이터 제공사와 보도는 보충 자료다. 원문 접근 실패를 확인된 원문으로 표시하지 않는다.

정정 공시와 재작성 비교 수치가 있으면 사용한 공시 버전을 기록한다. 과거 기준 분석에서는 그때 공개된 문서를 사용한다. 현재 웹페이지를 과거 스냅샷으로 취급하지 않는다. 같은 이름의 계정도 정의가 다르면 원래 정의를 함께 남긴다.

## 회계 비교

- 손익: 매출의 가격·물량·믹스, 영업이익률, 사업부 손익, 환율, 일회성 비용, 지배주주와 전체 순이익을 구분한다.
- 재무상태: 현금, 이자부 차입금, 리스 포함 범위, 순차입금, 매출채권·재고·매입채무, 자산·부채·자본을 대조한다.
- 현금흐름: CFO와 순이익의 차이, 운전자본, 유형/무형자산 취득 CAPEX, FCF, 배당·차입·증자를 연결한다. CAPEX는 유출의 양수 금액으로 정규화한 뒤 CFO에서 차감한다.
- 누적 공시에서 분기값을 구할 때 동일 회계 범위의 당기 누적에서 직전 누적을 뺀다. 연간 실적을 반기·분기와 같은 열에 놓지 않는다.
- 음수 순이익의 PER, 자본잠식의 PBR, 일회성 이익을 일반 업종 평균과 단순 비교하지 않는다.

은행·보험·증권은 일반 기업의 CFO/FCF를 기계적으로 해석하지 않는다. 순이자마진, 신용비용, 자본 적정성, 보험서비스손익, AUM·수수료 등 해당 사업에 맞는 공개 지표를 사용하고 미적용 이유를 적는다.

## 섹터별 분석 질문

최신 수치·점유율을 지식에 고정하지 않는다. 다음 질문을 기업 IR·공시와 지표의 원출처에서 확인한다. 다른 제품시장에 속한 경쟁사를 하나의 점유율 분모에 섞지 않는다.

| 섹터 | 사업 동인 | 비교 기준 |
| --- | --- | --- |
| 반도체·디스플레이 | 출하·ASP·제품 믹스·가동률·CAPEX | 메모리/파운드리/패널을 분리하고 기간을 맞춘다. |
| 2차전지 | 출하·판매단가·원재료 연동·재고·보조금 | 셀/소재·지역을 구분하고 보조금 포함/제외 이익을 분리한다. |
| 자동차 | 판매대수·지역/차종·인센티브·환율 | 완성차/부품, 도매/소매/수출을 구분한다. |
| 철강·화학 | 판매량·스프레드·원료·가동률 | 현물/계약가격과 원료 투입 시차를 기록한다. |
| 금융 | 이자/비이자 이익·신용비용·자본 | 은행/보험/증권의 회계·건전성 지표를 각각 사용한다. |
| 바이오 | 제품별 처방·허가·입찰·로열티·연구비 | 신약/바이오시밀러/CDMO의 시장과 수익 모델을 분리한다. |
| 인터넷 | 이용자·거래액·광고·수수료·인프라 비용 | GMV/매출, 총액/순액 인식, 이용자 정의를 확인한다. |
| 엔터 | 음반·공연·콘텐츠·정산·활동 일정 | 판매/출하와 총매출/순매출 및 이벤트 시차를 구분한다. |
| 산업재·기타 | 수주·잔고·매출 인식·원가·고객 투자 | 수주잔고의 취소·매출 인식 기간을 확인한다. |

## 파생·기술지표

베이시스는 같은 시각의 선물과 현물 및 특정 만기로 정의한다. 금리·배당·만기와 이론 베이시스를 고려하고 부호를 매매 신호로 바꾸지 않는다. 지수 옵션과 개별주식 옵션의 행사가·단위는 비교하지 않는다. OI는 매수·매도 양쪽 계약이 존재하므로 크기만으로 방향·딜러 순감마를 확정할 수 없다.

공매도잔고는 대차잔고가 아니다. PyKRX를 사용할 때 [공식 저장소](https://github.com/sharebook-kr/pykrx)에서 설치 버전의 함수·반환 필드를 확인하고 버전을 기록한다. API가 없으면 공식 화면 또는 확인 가능한 대체 출처를 사용하고, 그것도 없으면 미확보로 남긴다.

## 분석과 증거

무엇이 변했는지, 어떤 사업 동인에 연결되는지, 반대 증거는 무엇인지, 무엇을 보면 판단이 바뀌는지를 설명한다. 같은 보도자료의 재전재를 독립적인 복수 근거로 계산하지 않는다. 확인되지 않은 의견을 인용부호나 기관명으로 장식하지 않는다.
