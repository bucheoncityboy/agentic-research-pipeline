# 스킬 위치 변경

기업분석 RA 스킬은 독립 패키지인 [.agents/skills/company-analysis-ra/](../.agents/skills/company-analysis-ra/SKILL.md)로 이동했습니다.

그 폴더 전체에 지침·참고문서·실행 도구·템플릿·의존성 잠금 파일이 들어 있습니다. 다른 환경에서 사용할 때는 해당 폴더만 복사하고 폴더 안에서 `npm ci`를 실행합니다. 설치·등록 방법은 [스킬의 첫 실행 안내](../.agents/skills/company-analysis-ra/references/setup.md)를 따릅니다.
