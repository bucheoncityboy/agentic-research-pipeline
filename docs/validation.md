## 실제 자료 연결 검사의 범위

대상은 삼성전자 공식 Facts & Figures의 연간 손익 표, 2026년 1분기 실적 발표와 2분기 잠정실적 발표다. URL·페이지 형식에 맞춘 제한된 연결 검사이며 범용 DART·KRX 수집기가 아니다. 재무상태·현금흐름·시세·하우스 목표가의 완전 수집과 기업 분석 판단을 검증한 것으로 해석하지 않는다.

매 실행의 근거와 상태는 Git에서 제외한 `results/live-smoke/`에 저장한다. 원문 형식·기간·단위가 바뀌면 실패하며 이전 결과가 남을 수 있다. 이번 실행의 종료 코드와 fetch-status를 확인해야 한다.

## 남은 확인

초기 검수에서는 브라우저 보안정책이 file URL 접근을 차단해 실제 캔버스·모바일 화면을 확인하지 못했다. 이후 새 템플릿 개발 검수는 접근이 허용된 루프백 개발 서버에서 수행했다. 실제 A4 인쇄 페이지 배치는 아직 확인하지 않았다.

자동 게이트는 데이터 계약과 출력 일치를 검사한다. 외부 문서의 진위·정확한 인용·정정 공시 버전·최신 거래일·분석의 완결성은 원문 대조가 필요하다. 다른 운영체제·Node 버전 전체 조합과 강제 종료·동시 쓰기는 검수 범위에 포함하지 않는다.

## v3.2 배포 검수 (2026-10-12)

새 입력은 schemaVersion 3.2와 조사 범위·접근 시도·검수 기록을 사용한다. 기본 표준 범위는 사업/재무/밸류에이션/컨센서스/산업/공시/결론이다. audit는 필요한 상세 계정·본문·원문 숫자·화면 검수 누락을 점검한다. 입력과 생성기에 연결한 지문이 달라지면 검수를 갱신해야 한다. 3.1 입력은 호환하며 UNASSESSED로 구분한다.

- root/skill 타입 검사, skill-creator 메타데이터·로컬 참조 검사 통과.
- 전체 `tsx src/harness.ts`: 116개. 최종 판정 성공 조건, 필수 자료 누락, 원문 숫자 목록 누락, 입력/생성기 변경, 렌더링 오류/변조 출력, 가상 입력, 인쇄 검수 범위, 업종 계정 확장, 성장률의 0/음수 기준, audit 종료 코드 검증 포함.
- 양성 완료 조건은 가상 데이터에 비가상 플래그를 적용한 단위 계약 검사다. 실제 기업 조사 완료의 증거로 전달하지 않는다. 배포 예제는 fixture=true이며 DRAFT/PARTIAL, 가상 검수임을 표시한다.
- 독립 복사·설치, 개발 의존성 제외 설치, 외부 작업 위치에서 build/verify/audit, 아카이브 내용 검사 통과.
- Chart.js 4.5.1과 전체 MIT 라이선스를 HTML에 포함. 실제 브라우저에서 외부 script 0과 차트 5개 초기화를 확인. 생성 후 CDN 접속 불필요.
- 삼성전자 실제 입력에 핵심 판단·범위 표·YoY 관측치를 추가. 연간 손익 18행·재무상태 14행·현금흐름 14행, 데스크톱/375px 화면, 표 560px의 내부 가로 스크롤 40px, 출처 번호 이동·원본 PDF 링크, 콘솔 오류·경고 0 확인.
- 실제 샘플은 최신 밸류에이션·하우스 컨센서스와 모든 숫자의 독립 원문 검수 미완료를 기록한 DRAFT/PARTIAL이다. audit --final이 종료 2를 반환함을 확인했으며 전체 실제 분석 완료로 표시하지 않는다.

외부 원문·화면 검수는 수행 기록을 입력해야 한다. 지문과 자동 계약은 기록과 현재 버전의 연결을 검사하며 원문 진위나 사람/에이전트의 검수 행위를 자동 인증하지 않는다. 실제 A4 인쇄 페이지 배치와 다른 운영체제 전체 조합은 이 배포 검수에 포함하지 않는다.
