# 저장소 개인정보 점검

점검일: 2026-10-10 (Asia/Seoul). 배포 파일을 정리한 Windows 작업 사본과 로컬에 있는 Git 이력을 검사했다. 민감한 값은 기록하지 않고 파일 위치·유형·개수만 출력한다.

## 확인 범위

- 현재 Git 추적 파일과 추적 전의 배포·개발 파일.
- Git이 무시하는 파일 중 환경변수·키·개인 문서·private 디렉터리에 해당하는 파일 이름.
- 로컬 Git의 모든 참조에서 도달 가능한 과거 blob 40개와 커밋 메타데이터 4건. 추적 전 변경은 현재 파일 검사로 포함했다.
- 구버전 PDF 3종의 본문 전체와 PDF 정보·XMP 메타데이터. 중복 PDF는 내용 해시로 식별했다.
- 구버전 구조도 PNG의 메타데이터 문자열 검사와 화면 확인.

설치된 node_modules, 생성 결과 results, 로컬 배포 산출물 dist는 Git과 스킬 배포 패키지에서 제외한다. 점검 대상은 이 저장소이며 사용자 PC 전체를 검사한 것은 아니다.

## 결과

| 점검 항목 | 결과 |
| --- | --- |
| 이력서·자기소개서·지원서·동의서 등 개인 문서 이름 | 해당 파일 발견 없음 |
| API 토큰·인증 헤더·비공개 키·비밀번호 할당 패턴 | 발견 없음 |
| 요청자의 식별 문자열·개인 이메일·휴대폰·주민번호 패턴 | 발견 없음 |
| 개인 PC 절대 경로·로컬 파일 링크·사설 IP | 발견 없음 |
| Git 커밋 작성자·커미터 이메일 | GitHub 비공개 이메일 형식만 확인 |
| PDF 작성자 정보 | 한 파일에 리서치 제작기관 표기 확인, 요청자 식별 문자열·이메일·PC 경로 없음 |
| Git이 무시하는 민감 파일 후보 | 현재 사본에서 발견 없음 |

GitHub 공개 사용자명, 공개 기업명·재무 수치·공식 자료 URL은 자료와 출처로 남긴다. 원본 Git 이력은 변경하지 않았다.

## 재검사

```sh
npm run check:privacy
```

특정 개인 식별 문자열을 추가로 확인하려면 `--personal-term` 인자를 사용할 수 있다. 그 값은 검사 파일에 저장하지 않는다. 결과는 Git이 무시하는 `results/privacy-audit.json`에 저장한다. PDF 검사는 pdftotext·pdfinfo가 필요하며 추출 실패는 성공으로 처리하지 않는다.

`.gitignore`에 환경변수 파일, 비공개 키, 자격증명 파일, 개인 문서 이름, private/.local 디렉터리, 로컬 입력과 결과물의 제외 규칙을 추가했다. 이미 추적된 파일에는 제외 규칙이 소급 적용되지 않으므로 새 자료를 공유하기 전에 현재 파일과 Git 이력을 다시 확인한다.

이 검사는 알려진 문자열·파일명 패턴과 PDF 텍스트·메타데이터를 대상으로 한다. 모든 형태의 개인정보 부재를 증명하지 않으며 PDF 내부의 이미지·임베디드 첨부를 전부 육안·OCR로 확인한 검사는 아니다.
