# 검증 전 구버전 자료

이 폴더는 v3.0 시기의 보고서·입력·구조도 기록이다. 현재 v3.1 데이터 계약으로 재검증한 결과물이 아니며 최신 실행 예제로 사용하지 않는다. HTML·PDF는 디자인과 과거 작업 기록을 확인하는 용도다.

기존 examples/와 sample_output/의 동일한 파일 여섯 쌍은 SHA-256으로 대조한 뒤 한 벌만 남겼다. 삼성전자 구버전 JSON은 v3.1 입력과 호환되지 않고 자동 변환기는 제공하지 않는다. 구조도는 과거 미국기업 분석 흐름으로 현재 한국기업 스킬의 실행 구조와 다르다.

현재 실행 예제는 [스킬의 가상 fixture](../../.agents/skills/company-analysis-ra/fixtures/example.json), 실행 지침은 [SKILL.md](../../.agents/skills/company-analysis-ra/SKILL.md)를 사용한다.
